# Project_Tree（公開デモ・閲覧専用）

建設・土木の現場資料から、**時系列台帳・5段階のストーリー・資料用イメージ図・2D/3Dモデル**を
1つの画面でつなぐアプリです。2026-08 ハッカソン提出物。

## この公開版について

**閲覧専用で動かしています。** 同梱データ（案件23件・資料112件・記録431件・イメージ図14枚・3Dモデル）の
閲覧と資料出力はすべてお試しいただけますが、資料の取り込みとLLMの実行は無効にしています。
このアプリは本来ローカル（127.0.0.1）で動かす前提のため、公開先では書き込み系を止めています。

**全機能（資料の取り込み・LLM実行）を試す場合は、GitHubの手順でお手元に導入してください。**
→ https://github.com/009-next/Project_Tree

## 触っていただきたい順番

1. 左の一覧から **「河川護岸整備工事」** を選ぶ（記録・イメージ図・3Dモデルが全部そろっています）
2. 上段の段階カードを **左クリック** → 根拠となる記録・原文が開く
3. 段階カードを **右クリック** → md / pdf / word / pptx / xlsx で資料を出力
4. 下段の3Dモデルの部位を **左クリック** → 対応する段階カードが光る
5. 右上の「表示段階」スライダー → 指定した段階までの部材だけを表示

3Dモデルの生成に Blender は不要です（台帳の部材データからローカルで組み立てています）。
