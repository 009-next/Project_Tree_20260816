# 河川護岸整備工事 キックオフ議事録

2026年5月11日

## 出席者
- 発注者：〇〇県土木事務所 河川課 担当者
- 受注者：当社 現場代理人、監理技術者、担当設計技術者

## 議題
1. 工事概要の確認
2. 施工体制・工程の説明
3. 安全管理・環境配慮事項の確認
4. 今後の連絡体制

## 議事内容

### 1. 工事概要
- 案件名：河川護岸整備工事（以下、本件護岸整備または河川案件と呼称）
- 施工延長：約450m
- 主要工種：護岸ブロック積、法面整形、天端保護工
- 工期：2026年5月〜2026年10月末（予定）

### 2. 施工体制・工程
- 現場代理人および監理技術者を選任済み。専任配置とする。
- 全体工程は月次工程表にて管理し、月例会議で進捗確認を行う。
- 増水期（出水期：6月〜9月）を考慮し、河川内作業は極力早期に完了させる方針を確認。

### 3. 安全管理・環境配慮事項
- 河川内作業時は水位・気象情報を常時監視し、警報発令時は即時退避。
- 周辺農地への影響（濁水・土砂流出）について、仮設沈砂池・土のう設置を検討する旨説明。
- 近隣住民・農業関係者への事前周知を実施予定。

### 4. 今後の連絡体制
- 定例会議は毎月第2週に実施。
- 緊急時連絡網を発注者・受注者双方で整備し共有する。

## 決定事項
- 出水期前の河川内工事を優先的に進める工程とする。
- 濁水対策として仮設沈砂池の設置を次回打合せまでに検討・提案する。

2026年6月中旬（詳細日程は別途調整）
