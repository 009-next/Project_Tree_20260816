# 東部橋梁補修工事 キックオフ会議議事録

**開催日**: 2026年3月13日（金）
**場所**: 東部土木事務所 会議室A
**出席者**: 発注者（東部土木事務所）、受注者（当社：現場代理人・主任技術者）、設計担当

## 1. 案件概要
- 案件名: 東部橋梁補修工事
- 工事場所: 東部地区 一級河川橋梁（東部橋）
- 工期: 2026年4月1日～2026年7月31日（予定）
- 工事内容: 床版補修、伸縮装置取替、高欄補修、塗装補修一式

## 2. 議事内容
1. 施工体制の確認
   - 現場代理人、主任技術者を発注者に届出済みであることを確認。
   - 協力会社（橋梁補修専門業者）の選定完了。
2. 交通規制計画について
   - 本橋は幹線道路に架かるため、片側交互通行規制での施工を基本方針とする。
   - 規制計画は所轄警察署との協議が必要であり、協議完了まで着手不可の工種があることを確認。
3. 資材調達について
   - 伸縮装置、高欄材料は特注品のため、発注から納品まで約8週間を要する見込み。早期発注を指示。
4. 安全管理
   - 河川内作業を伴うため、増水時の避難計画を別途作成すること。
5. 今後のスケジュール
   - 交通規制協議：3月末までに警察署へ申請書提出
   - 資材発注：3月中に完了させること
   - 着工：4月1日を予定

## 3. 決定事項
- 次回定例会議は4月10日開催とする。
- 交通規制協議の進捗は都度発注者へ報告すること。
